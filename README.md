# Clip Relay Legal Site

A tiny static site for Clip Relay's public app information.

## Before publishing

Search the files for:

    YOUR_PUBLIC_SUPPORT_EMAIL

and replace it with the public email address you want TikTok/other platforms to see.

## Suggested TikTok description

Desktop app for publishing and scheduling short-form videos to connected social accounts.

## Publish with GitHub Pages

Recommended repository name:

    clip-relay-legal

1. Create a new public GitHub repository named `clip-relay-legal`.
2. Copy the CONTENTS of this folder into the repository.
3. Commit and push.
4. On GitHub: Settings -> Pages.
5. Under Build and deployment, choose `Deploy from a branch`.
6. Select branch `main` and folder `/ (root)`.
7. Save and wait for GitHub Pages to deploy.

If your GitHub username is `Theo524`, the URLs should normally become:

    https://theo524.github.io/clip-relay-legal/
    https://theo524.github.io/clip-relay-legal/terms/
    https://theo524.github.io/clip-relay-legal/privacy/

Use the final live URLs in TikTok Developer Portal after confirming they open publicly.

## Files

- `index.html` - public Clip Relay landing/legal hub
- `terms/index.html` - Terms of Service
- `privacy/index.html` - Privacy Policy
- `assets/style.css` - visual styling

## App icon

TikTok currently asks for a 1024x1024 JPG/JPEG/PNG icon under 5 MB. The icon is supplied separately from this site bundle.
